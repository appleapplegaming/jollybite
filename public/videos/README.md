# Video Files Directory

This directory should contain video files for menu items displayed on the homepage.

## Video Guidelines

1. **File Size**: Keep videos under 5MB each for fast loading
2. **Duration**: 5-15 seconds is ideal for looping content
3. **Quality**: Balance between visual quality and file size
4. **Format**: MP4 with H.264 codec for best browser compatibility
5. **Dimensions**: Maintain consistent aspect ratio across videos
6. **Content**: Focus on the food, making it look appealing and appetizing

## Fallback Behavior

If video files are not available or fail to load, the MenuItem component will automatically fall back to displaying static images from the URLs configured in Homepage.astro.
